## Featured: NIST SP 800-53 Rev. 5 LOW Baseline Package

A complete control package for a live production system (Community Tech Aid, an AI tech-support web app that takes payments and holds user data), assessed against NIST SP 800-53A Rev. 5.

| Document | What it is |
|---|---|
| [01 - System Security Plan](cta-nist-800-53-package/01-system-security-plan.md) ([PDF](cta-nist-800-53-package/01-system-security-plan.pdf)) | Authorization boundary, data flows, customer responsibility matrix, 136 control implementation statements |
| [02 - Security Policy Manual](cta-nist-800-53-package/02-security-policy-manual.md) ([PDF](cta-nist-800-53-package/02-security-policy-manual.pdf)) | 18 control-family policies |
| [03 - Security Assessment Report + POA&M](cta-nist-800-53-package/03-security-assessment-report.md) ([PDF](cta-nist-800-53-package/03-security-assessment-report.pdf)) | Per-control determinations, 20 findings, 20-item POA&M |
| [04 - Security Posture Summary](cta-nist-800-53-package/04-security-posture-summary.md) ([PDF](cta-nist-800-53-package/04-security-posture-summary.pdf)) | Plain-language results for non-technical readers |

**Results:** 136 controls assessed · 42 Satisfied · 25 Satisfied (Inherited) · 51 Other Than Satisfied · 18 Not Applicable. Seven weaknesses self-identified and remediated, including broken access control and a forgeable audit log. [Full package overview](cta-nist-800-53-package/)
