# Security Policy

This repository is a cybersecurity portfolio - a collection of projects, labs, and documentation demonstrating security skills. It is not production software and does not follow a versioned release/support model.

## Reporting a Vulnerability

If you find a security issue in any code sample or script here, open an issue or contact contact@ebizmarket.net. I'll respond within 5 business days.

## Scope

Findings related to actual vulnerabilities in code within this repo are welcome. This repo does not process user data or run as a live service.
